我的第一个网站上线了

2026-04-22

今天把第一个网站做出来了，地址是 ziyo8686.github.io/my-website。这件事听起来很小，但对一个之前完全没碰过网页的人来说，看到自己写的字真真切切地出现在浏览器地址栏里，那种感觉还挺奇妙的。

它长什么样

就一张居中的卡片，垫在一层蓝到青的渐变背景上。卡片里有一个圆形头像位、一句“你好，我是 ZiYo”，还有一个按钮——点下去会弹出一个提示框，写着“恭喜！你的网站已经升级完成啦！”。

功能少到几乎不能叫“功能”，但我把它当成一个起点：先让一个页面跑起来，再谈别的。

过程中搞明白的事

  • 网页其实就是文本。 一个 HTML 文件，浏览器读它就渲染成页面。没有什么神秘的东西藏在后面。
  • CSS 决定样子，HTML 决定内容。 两者分开写，改颜色的时候不用动文字。
  • GitHub Pages 是免费的。 把文件传上去，点几下开关，全世界就能访问了。

一些没想到的细节

比如那个头像圆圈，我以为随手写个 class 就行，结果漏了个等号，整个样式就全都不生效了——页面看起来没报错，只是安静地跟你想的不一样。这类“静默失败”后来我又遇到过好几次，也慢慢养成了回头核对一遍的习惯。

先让它跑起来，再让它好看。这句话我打算一直用下去。

下一步想做的，是把它从一个“单张卡片”变成一个真的能逛一逛的地方。
